# 橙子的主题工坊

在 SillyTavern 里制作自己的美化。从内置作品或空白开始，调整排版、字体、配色和图片，也可以直接查看真实界面的效果。

## 安装

在酒馆的「扩展 → 安装扩展」中粘贴仓库地址。

https://github.com/yanxu-orange/ST-Orange-ThemeStudio

需要 SillyTavern 1.18.0 或更高版本。电脑和手机使用同一个扩展。如果安装过测试版，启用公开版前请先停用测试版。

## 使用

- 在魔棒、扩展面板或悬浮入口打开工坊，选择「从已有作品开始」或「从空白开始」。
- 「保存草稿」方便接着编辑。「更多 → 另存为作品」可以把当前方案命名后存入作品库。
- 「应用到酒馆」保留当前美化并返回酒馆。需要恢复酒馆外观时，选择「停用美化」。
- 方案支持导入和导出。

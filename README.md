# 绘境

通过图文素材拼贴与位置调整，实现实时的酒馆自定义美化。
支持文字、图片、图标与配色自由组合。

## 安装
在 SillyTavern 的「扩展 → 安装扩展」中粘贴：
https://github.com/yanxu-orange/ST-Orange-ThemeStudio

支持 PC 和移动端，需要 SillyTavern 1.18.0 或更高版本。

## 开始使用
0.选择酒馆的默认空css美化。
1. 从魔棒菜单或扩展面板打开绘境。
2. 从空白开始，或选择已有作品。
3. 选择编辑区域，调整文字、图片、排版与配色。
4. 应用到酒馆。


## 主要功能
• 酒馆实时美化
• 美化方案保存与导出

# 绘境

通过图文素材拼贴与位置调整，实现实时的酒馆自定义美化。
支持文字、图片、图标与配色自由组合。

## 安装
在 SillyTavern 的「扩展 → 安装扩展」中粘贴：
https://github.com/yanxu-orange/ST-Orange-ThemeStudio

支持 PC 和移动端，需要 SillyTavern 1.18.0 或更高版本。

## 开始使用
0.选择酒馆的默认空css美化。
1. 从魔棒菜单或扩展面板打开绘境。
2. 从空白开始，或选择已有作品。
3. 选择编辑区域，调整文字、图片、排版与配色。
4. 应用到酒馆。


## 主要功能
• 酒馆实时美化
• 美化方案保存与导出

## 0.27.0 更新

- 头像区新增等比制作画布，在「区域设置」启用，随窗口宽度整体缩放拼贴。
- 顶栏支持灵动岛，收起按钮可换色、换图标并拖动贴边。
- 导出方案时可以自定义文件名。
- 减少含图片方案在多楼层排版时的重复处理。

原有方案继续按原布局读取。新画布需手动启用，启用后保存或导出的方案需要新版绘境读取。
